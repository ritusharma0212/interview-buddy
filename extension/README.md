# Experimental Chrome extension

1. Download the `extension` folder from this branch.
2. Open `chrome://extensions`, enable Developer mode, and select **Load unpacked**.
3. Select the extension folder.
4. Open a LinkedIn or HiringCafe job. Select the job description if it is not automatically detected.
5. Click the extension, select Import, and approve the text transfer.
6. In the new Interview Breakthrough tab, extract company and role, review, and save.

For Vercel Preview testing, replace the popup's app URL with the exact preview origin. This extension is not published or verified on LinkedIn/HiringCafe. It does not access cookies and operates only when clicked. Check third-party site terms before use.
